# Argus

Digitales Koordinierungswerkzeug für Sammelstellen bei Großschadenslagen.

Mehrgeräte-fähige Progressive Web App (PWA) — installierbar auf dem iPhone-Homescreen, offline-fähig, Echtzeit-Sync über Cloud-Backend.

## Status

- `legacy/` – erproter HTML-Prototyp (Referenz)
- `index.html` – aktive Entwicklungsversion (Phase 1: Backend-Anbindung läuft)

## Starten (Entwicklung)

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

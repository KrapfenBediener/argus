# ARGUS — Marken-Assets (Logo)

Freigestellt aus `ARGUS_Icon.png` (Hintergrund entfernt, transparent). Erzeugt mit
`scripts/argus_logo_extract.py` — bei Bedarf reproduzierbar.

| Datei | Inhalt | Verwendung |
|---|---|---|
| `argus-logo.png` | A + Kreuz + Schriftzug „ARGUS", **dunkel** | auf **hellen** Hintergründen (Dokumente, helle Folien, Briefkopf) |
| `argus-logo-light.png` | dasselbe, **weiß** (Kreuz bleibt rot) | auf **dunklen** Hintergründen (Launch-Deck, dunkle Banner) |
| `argus-mark.png` | nur Symbol (A + Kreuz), **dunkel** | App-/Favicon-Idee, enge Stellen, neben separatem Schriftzug |
| `argus-mark-light.png` | nur Symbol, **weiß/rot** | dunkle Hintergründe, neben separatem Schriftzug |

- Transparenter Hintergrund (PNG). Seitenverhältnis beibehalten (nicht verzerren).
- Originalfarben: Navy `#1f2530`-Bereich, Kreuz-Rot ~ `#C62828`.
- Quelle/Original-Icon (gerundetes App-Symbol) bleibt `ARGUS_Icon.png` / `icon-180/192.png`.

   - `if argus_admin_praesidium_id() is null or p_praesidium_id <> argus_admin_praesidium_id()

   Dann anlegen — als security definer umgeht der RPC die master-only-RLS gezielt
   und kontrolliert: gast=true, is_admin=false, is_master=false, observer=false,
   single_use=false, temporary=false, ttl_hours=null, praesidium_id=p_praesidium_id,
   expires_at = (extract(epoch from now())*1000)::bigint + 24*3600000, frischer
   short_code (verwechslungssicheres Alphabet ohne 0/O/1/I — gen-Logik wie genShortCode
   der Leitungs-Seite: 8 Zeichen aus 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789', Format XXXX-XXXX),
   token = encode(extensions.gen_random_bytes(16),'hex'), label = btrim(coalesce(p_label,'')).

   access_tokens vorhanden (max. ein paar Versuche). Zwangs-Log: governance_log-Eintrag
   action 'admin_gast_issue', kuerzel=neuer short_code. Rückgabe: jsonb {short_code, expires_at}.

2. `argus_admin_revoke_gast(p_short_code text)` returns jsonb, security definer.
   Guards: argus_is_admin()-Pflicht; Zielcode laden
   (`select praesidium_id, is_master, is_admin, observer, gast into … where short_code = …`).
   Verweigern, wenn nicht gefunden („Code nicht gefunden") ODER Ziel-praesidium_id
   <> argus_admin_praesidium_id() („Nur fürs eigene Präsidium") ODER der Zielcode

   coalesce(observer,false) → „Nur Gast-Codes des eigenen Präsidiums sperrbar".

   Admin darf NIE einen Dauer-/Einmal-/Master-/Observer-/Admin-Code sperren. Erst dann
   `update access_tokens set revoked = true where short_code = p_short_code`. Zwangs-Log:
   action 'admin_gast_revoke', kuerzel=p_short_code. Rückgabe {revoked:true}.
   grant execute to anon.

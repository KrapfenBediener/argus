## Rückgabeformate der neuen/geänderten RPCs (für Pläne 04.9-02/03)

- **`argus_check_code(code text)`** → `{"found": bool, "revoked": bool}` — immer
  HTTP 200, keine Seiteneffekte, kein JWT, kein Präsidiums-Leak. Für den
  Re-Check der Feld-App beim Start/Reconnect (offline nie blockieren).
- **`argus_exchange_code(code text)`** → unverändert; NEU: bei gesperrtem Code
  `{"error": "Code wurde gesperrt"}` (HTTP 200 mit error-Key, wie die übrigen
  Fehlertexte; unterscheidbar von „Ungültiger oder verbrauchter Code").
- **`argus_close_einsatz(p_ccp_id, p_typ, p_frist_tage default null)`** →
  unverändert `{"closed_at", "purge_after", "photo_purge_after", "ccp_count"}` —
  beide Fristen = Abschluss + 72 h; `p_frist_tage` wird ignoriert (Altgeräte
  dürfen ihn weiter senden, neue Aufrufer lassen ihn weg).
- **`argus_governance_einsaetze()`** → jsonb-Array, je Element:
  `ccp_id, kennung, merge_group_id, einsatz_typ, closed_at, purge_after,
  photo_purge_after, patient_count, photo_count, checklist_count`
  (Sortierung `closed_at` absteigend; `[]` wenn leer). Filter = wörtlich die
  Purge-Bedingung (b): vollständig gepurgte Tombstones erscheinen NICHT mehr —
  die stehen nur noch im `purge_log`.
- **`argus_governance_protokoll(p_ccp_id, p_kuerzel)`** →
  `{"ccps": [...], "patients": [...], "checklists": [...]}`;
  ccps-Elemente: `id, kennung, einsatz_typ, closed_at, purge_after,
  photo_purge_after, ort`; patients = volle Patienten-Rows MINUS
  `photo`/`locked_by`/`locked_at`, PLUS `has_photo` (bool); checklists = volle
  Rows (`to_jsonb`). Verbund (merge_group) wird komplett geliefert.
  JEDER Aufruf erzeugt einen `protokoll_view`-Log-Eintrag. Fehler als Exception
  (HTTP 400): kein Master / Kürzel leer / CCP nicht gefunden / Einsatz noch offen.
- **`argus_extend_protokoll_frist(p_ccp_id, p_kuerzel, p_grund, p_stunden default 72)`**
  → `{"purge_after": <ms>}`; wirkt auf purge_after des ganzen Verbunds;
  1–720 Stunden; nur abgeschlossene Einsätze. Fotos sind davon NICHT betroffen.
- **`argus_governance_photo(p_patient_id, p_kuerzel)`** → unverändert
  `{"photo": ...}` + `foto_view`-Log (bleibt der einzige Foto-Abrufweg, Lazy-Load).

**governance_log.action-Werte:** `foto_view` | `frist_verlaengert` | `protokoll_view`.

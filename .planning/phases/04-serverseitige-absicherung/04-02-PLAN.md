# Plan 04-02: App-JWT-Integration

**Phase:** 4 — Serverseitige Absicherung  
**Wave:** 2 (nach 04-01 — Edge Function muss deployt sein)

## Objective

Die App ersetzt `validateInviteToken()` durch einen Edge-Function-Aufruf.
Der Supabase-Client wird mit dem JWT als Authorization-Header initialisiert.
Stille JWT-Verlängerung und Migrations-Logik für bestehende Geräte werden eingebaut.
Kein sichtbarer Login-Schritt — der Nutzer gibt seinen Code einmal (neu) ein.

`validateInviteToken()` wird durch `exchangeCode()` ersetzt (alte Funktion bleibt als
Fallback bis Plan 04-03 nur noch für Notfall-Zugang falls Edge Function nicht erreichbar).

```
async function exchangeCode(code){
  var clean = code.replace(/[\s\-]/g,'').toUpperCase();
  if(clean.length < 8) return null;
  try{
    var resp = await fetch(SUPA_URL+'/functions/v1/exchange-code', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'apikey': SUPA_KEY
      },
      body: JSON.stringify({ code: clean })
    });
    if(!resp.ok) return null;
    var data = await resp.json();
    if(!data.jwt) return null;
    // JWT + Ablaufzeit persistieren
    localStorage.setItem('argus_jwt', data.jwt);
    localStorage.setItem('argus_jwt_exp', String(data.exp * 1000)); // in ms
    // Rückgabe-Format kompatibel zu altem validateInviteToken
    return {
      praesidium_id: data.praesidium_id,
      is_master: data.is_master,
      praesidien: data.praesidium_name ? { id: data.praesidium_id, name: data.praesidium_name } : null,
      short_code: clean.slice(0,4)+'-'+clean.slice(4),
      temporary: data.ttl_seconds < (30*24*3600),
      ttl_hours: Math.round(data.ttl_seconds / 3600),
      single_use: false // bereits serverseitig verbraucht
    };
  }catch(e){ return null; }
}
```

Überall wo `validateInviteToken(...)` aufgerufen wird, ersetzen durch `exchangeCode(...)`:
- `checkunlock`-Handler (vPraesidium-Eingabefeld)
- `checkinvite`-Handler (vLocked-Eingabefeld)
- Init-Flow für `#code=` und `#inv=` URL-Parameter

`consumeSingleUse()` ist nach diesem Plan überflüssig (Edge Function macht das),
bleibt aber defensiv für Altfälle.
</action>

<action>
`sb()` so umschreiben, dass es bei vorhandenem `argus_jwt` den Client mit JWT-Header
erstellt. Bei JWT-Wechsel (z. B. nach Refresh) wird der Client neu erstellt und
das bestehende Realtime-Abo getrennt (es wird dann durch den Aufrufer neu gesetzt).

Zwei neue globale Variablen nach den bestehenden globals einfügen:
```
var _sbJwt = null;  // JWT-String zum Erkennen ob Neuinitialisierung nötig
```

Neue `sb()`:
```
function sb(){
  var currentJwt = localStorage.getItem('argus_jwt');
  if(_sb && currentJwt === _sbJwt) return _sb;
  if(!window.supabaseLib || !window.supabaseLib.createClient) return null;
  // JWT hat sich geändert (Refresh) → Realtime trennen, Client neu erstellen
  if(_channel){ try{_channel.unsubscribe();}catch(e){} _channel=null; }
  _sbJwt = currentJwt;
  var headers = currentJwt ? { Authorization: 'Bearer '+currentJwt } : {};
  _sb = window.supabaseLib.createClient(SUPA_URL, SUPA_KEY, {
    auth:{ persistSession:false, autoRefreshToken:false, detectSessionInUrl:false },
    global:{ headers: headers }
  });
  return _sb;
}
```

`persistSession:false` und `autoRefreshToken:false` weil wir das JWT manuell verwalten.
</action>

<acceptance_criteria>
- `sb()` liest `argus_jwt` aus localStorage bei jedem Aufruf
- Bei gleichem JWT: cached Client zurückgeben (kein Recreate)
- Bei geändertem JWT: `_channel.unsubscribe()` + neuen Client mit neuem JWT-Header
- `persistSession:false` und `autoRefreshToken:false` gesetzt
- `_sbJwt` globale Variable vorhanden
</acceptance_criteria>

<action>
Funktion `refreshJwtIfNeeded()` anlegen (nach `exchangeCode`):

```
async function refreshJwtIfNeeded(){
  if(!navigator.onLine) return; // offline = kein Refresh nötig
  var jwt = localStorage.getItem('argus_jwt');
  var exp = parseInt(localStorage.getItem('argus_jwt_exp') || '0');
  if(!jwt || !exp) return;
  var sevenDays = 7 * 24 * 3600 * 1000;
  if(exp - nowMs() > sevenDays) return; // noch frisch
  // Stored Code für Refresh holen
  var storedCode = localStorage.getItem('argus_invite') || '';
  if(!storedCode) return;
  var result = await exchangeCode(storedCode);
  if(result){
    // sb() erkennt automatisch das neue JWT beim nächsten Aufruf
    if(_ccpId && sb()) subscribeRealtime();
  }
}
```

`refreshJwtIfNeeded()` im init-Block aufrufen — nach dem JWT-Check, vor `loadMeta()`.
</action>

<acceptance_criteria>

- Wird nur aufgerufen wenn `navigator.onLine` true
- Prüft ob `argus_jwt_exp` in localStorage vorhanden
- Ruft `exchangeCode()` mit `argus_invite` nur wenn < 7 Tage Restlaufzeit
- Nach erfolgreichem Refresh wird `subscribeRealtime()` neu aufgerufen
</acceptance_criteria>

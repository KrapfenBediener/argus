## Sampling Rate

- **After every task commit:** Run `node --test tests/sync.test.cjs && node scripts/check-syntax.mjs`
- **After every plan wave:** Run `npm run ci`
- **Before `/gsd-verify-work`:** `npm run ci` grün + `npm run check:rls` + SQL-Proben (Merge/Grabstein/Late-Push) belegt + manueller 2-Geräte-UAT
- **Max feedback latency:** 10 seconds

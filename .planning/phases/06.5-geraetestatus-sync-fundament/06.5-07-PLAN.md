## Funkspruch-Vertrag (Tests in tests/funk.test.cjs, exakte Erwartungen)
- `funkText(c)`, c = `{kennung, ort, hhmm, t1, t2, t3, t5, prio, gpa, tq}`: `'CCP ' + NATO-Wort(e) + (ort ? ', '+ort : '') + ', ' + hhmm + ' — ' + Teile.join(', ') + '.'`; Teile = `<zahl> Rot`, `<zahl> Gelb`, `<zahl> Grün`, `<zahl> Schwarz`, `<zahl> Prio`, `<zahl> abtransportiert`, TQ-Teil. Zahlwörter 0–12 (`null, ein, zwei, drei, vier, fünf, sechs, sieben, acht, neun, zehn, elf, zwölf`), ab 13 Ziffern. TQ-Teil: 0 → `kein Tourniquet läuft`, 1 → `ein Tourniquet läuft`, n ≥ 2 → `<zahl> Tourniquets laufen`. Kennung mit `/` (Verbund) → NATO-Wörter mit `/` verbunden (`Alpha/Bravo`). NATO A–Z (Alpha, Bravo, Charlie, Delta, Echo, Foxtrot, Golf, Hotel, India, Juliett, Kilo, Lima, Mike, November, Oscar, Papa, Quebec, Romeo, Sierra, Tango, Uniform, Victor, Whiskey, X-Ray, Yankee, Zulu). Alle Tabellen INNERHALB der Funktion (Farbwörter als eine Zeile `{T1:'Rot',T2:'Gelb',T3:'Grün',T5:'Schwarz'}` mit Kommentar „Trainer-Abstimmung offen: Farbwörter vs. T-Kategorien — nur diese Zeile ändern").
- `funkSds(c)` (c zusätzlich `nr`): `'ARG1|' + kennung.replace(/\//g,'+') + '|' + hhmm ohne ':' + '|' + nr + '|T1=' + t1 + ',T2=' + t2 + ',T3=' + t3 + ',T5=' + t5 + ',P=' + prio + ',G=' + gpa + ',TQ=' + tq`.
- Beide lesen NUR Felder von `c` — keine Patientenfelder, kein `patients` (D6.5-10; Test prüft den Quelltext).

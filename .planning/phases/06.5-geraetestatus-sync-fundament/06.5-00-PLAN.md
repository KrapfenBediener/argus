## Verträge der reinen Funktionen (verbindlich für Pläne 03–07; hier nur als Tests festgeschrieben)

Alle Funktionen sind top-level `function NAME(...)`-Deklarationen in `index.html`, lesen KEINE Globals (Konstanten liegen in der Funktion oder kommen als Parameter). Ausnahme: Funktionen dürfen andere Vertrags-Funktionen aufrufen — Tests werten sie dann gemeinsam per `evalFunctions(script, [namen])` aus.

- `var FGROUPS` (Objekt-Literal, Plan 03): `{cat:['cat','lastTriage'], st:['status','prio','ready'], vit:['vit','pupRe','pupLi'], tx:['tx'], tq:['tqStart','tqSite'], stamm:['name','age','gender','allergies','moi','injury','fr','notes','inj'], foto:['photo']}` — genau diese 7 Gruppen (D6.5-06).
- `groupSig(p, keys)` → String; Foto-Feld `photo` wird als `'P'+länge+':'+letzte 24 Zeichen` signiert (leer → `''`), alle anderen per `JSON.stringify(v==null?'':v)`, verbunden mit `'\u0001'`.
- `groupSigs(p, groups)` → `{g: groupSig(p, groups[g])}`.
- `changedGroups(p, groups)` → Array der Gruppen, deren `groupSig` von `p._sig[g]` abweicht; fehlt `p._sig` → alle Gruppen.
- `nextStamp(now, last)` → `Math.max(now, (last||0)+1)`.
- `stampGroups(p, gs, t, dev)` → setzt für jede Gruppe g in gs `p.fts[g] = {t, d:dev, b:basis, p:1}` mit basis = (altes `p.fts[g].p` gesetzt ? altes `.b` : altes `.t` oder 0); legt `p.fts` an, falls fehlt; gibt p zurück.
- `ftsForUpload(fts)` → Kopie ohne `p`-Flags (nur `t,d,b`; Schlüssel `ack` → nur `t`).
- `clearPending(fts, upTo)` → entfernt `p` in allen Einträgen mit `t <= upTo`; gibt fts zurück.
- `mergeGroups(local, cloud, groups)` → neues Objekt (Basis = Kopie von cloud): Grabstein-Regel (Gruppe `del`: lokal gewinnt nur bei `local.fts.del.t > cloud.fts.del.t`, Fallback cloud: `cloud.deletedAt`); ist das Ergebnis ein Grabstein → Inhalt geleert (wie `tombstoneHull`, Kategorie bleibt). Sonst je Gruppe: `tl` = `local.fts[g].t`, fehlt → (`groupSig` lokal ≠ cloud ? `local.updated` : 0); `tc` = `cloud.fts[g].t` sonst `cloud.updated` sonst 0; nur `tl > tc` → lokale Felder + lokaler Stempel (bei Fallback `{t:local.updated, d:0}`). `updated` = Maximum. Nutzt `groupSig`.
- `clockSample(t0, t1, serverMs)` → `{rtt: t1-t0, offset: serverMs-(t0+t1)/2}`.
- `pickOffset(samples)` → gerundeter Offset der Probe mit kleinster RTT unter allen mit `rtt < 1500`; keine → `null`.
- `clockHint(offset)` → `''` bei `|offset| <= 5000`; sonst `'Geräteuhr geht N s vor — wird herausgerechnet'` (offset < 0 = Gerät geht vor) bzw. `'… nach …'` (offset > 0); N = `Math.round(|offset|/1000)`; ab 120 s stattdessen `'N min'` mit N = `Math.floor(|offset|/60000)`.
- `devStatus(d, now)` → `'verlassen'` (wenn `d.left_at`), sonst `'verbunden'` (wenn `now - d.last_seen < 30000`), sonst `'abgemeldet'` (wenn `d.lost_at`), sonst `'ausser_reichweite'`.
- `devLabel(d, now, o)` (nutzt `devStatus`; o = `{mm, merged, hhmm}`) → Präfix = (`o.merged` ? `d.kennung+'·'` : '') + `d.device_no` + (Bediener == o.mm ? `' ★'` : '') + (Bediener ? `' '+Bediener` : ''); verbunden → Präfix; außer Reichweite → Präfix + `' — außer Reichweite seit M min'` (M = max(1, floor((now-last_seen)/60000))) + offen-Zusatz; abgemeldet → Präfix + `' — abgemeldet'` + (open_n>0 ? `' (n Patient(en) möglicherweise verloren)'` : ''); verlassen → Präfix + `' — verlassen '+o.hhmm(d.left_at)` + offen-Zusatz. offen-Zusatz = open_n>0 ? `' (n Patient offen)'` bzw. `' (n Patienten offen)'` : ''.
- `leaveText(kennung, dev, n, isMM)` → `'CCP '+kennung+' verlassen?\n\n'` + Teile: dev>0 → `'Du bist Gerät '+dev+' · '` + Rest; Rest = n>0 ? `n+' Patient(en) noch nicht synchronisiert'` : `'alles synchronisiert'`; bei dev==0 beginnt die Zeile mit großem Anfangsbuchstaben (`'Alles synchronisiert'`); isMM → zusätzlich `'\n\nDu bist MasterMedic — die Rolle bleibt bei dir, bis jemand sie übernimmt.'`.
- `closeCompleteness(devs, now, own, merged)` (nutzt `devStatus`) → `{total, ok, text}`; own = `{dev, dirty}` überschreibt/ergänzt die eigene Gerätezeile (gilt als verbunden, open_n = own.dirty). Bestätigt = open_n==0 und Status verbunden oder verlassen. text = `''` wenn alle bestätigt; sonst `'K von N Geräten haben alles bestätigt — '` + Probleme, verbunden mit `'; '`; Problem = `'Gerät '+label` + (außer Reichweite → `' außer Reichweite'`, abgemeldet → `' abgemeldet'`) + (open>0 ? `', n Patient(en) offen'` : ''); label = merged ? `kennung+'·'+nr` : nr. devs null oder leer → `{total:0, ok:0, text:'Gerätestand unbekannt (keine Verbindung)'}`.
- `nachfristOk(closedAt, now, purgeAfter)` → `!!closedAt && now < closedAt + 86400000 && (!purgeAfter || now < purgeAfter)`.
- `localPurgeDecision(ctx, now)` → `{dropPhoto, dropRecord, dropLate}`; ctx = `{closedAt, dirty, hasPhoto, lastContact}`; H = 3600000. Mit closedAt: dropPhoto = hasPhoto && now >= closedAt+72H; dropRecord = !dirty; dropLate = dirty && now >= closedAt+24H. Ohne closedAt, mit lastContact: dropRecord = !dirty && now >= lastContact+72H; dropLate = dirty && now >= lastContact+60*24H; dropPhoto = false. Ohne beides: alles false.
- `tombstoneHull(p, by, dev, t)` (Plan 04) → leert Inhalt: name/age/gender/allergies/moi/injury/fr/notes `''`, pupRe/pupLi `''`, vit `{af:'',spo2:'',hf:'',rr:'',avpu:'',pain:''}`, tx `{}`, inj `[]`, tqStart/tqSite `null`, photo `null`, status `'verworfen'`, prio/ready `false`, deletedAt `t`, deletedBy `by`, deletedDev `dev`; behält id, num, ccp, cat, lastTriage, created, ccpId, by, fts; gibt p zurück.
- `funkText(c)` und `funkSds(c)` (Plan 07) — Erwartungswerte siehe Task 3.

### `index.html` - `patToRow`/`patFromRow` (model, transform)

**Analog:** `index.html:455-482`. Beide Funktionen sind die einzige Mapping-Stelle camelCase <-> snake_case. `patFromRow` läuft durch `normalize` (`:1957`), dort müssen neue Felder Defaults bekommen (`fts={}`, `deletedAt=null`, `conf=[]`).


Anpassung: `fts:p.fts||{}`, `deleted_at/by/dev` ergänzen, `conf` NICHT senden (serverseitig gepflegt). **D6.5-18 Schema-Probe:** neue Spalten nur in die Row aufnehmen, wenn `_schemaV>=25` (Capability-Probe beim Start); sonst scheitert JEDER Upsert an `PGRST204`. `_sig`, `_dirty` bleiben lokal (werden von `patToRow` nie gesendet, genauso wie heute `_dirty`).

### Tests: Extraktions-Muster für reine Funktionen

**Mechanik** (`tests/_extract.cjs`): `extractFunction(script, name)` sucht per Regex `function\s+NAME\s*\(` die ERSTE Deklaration und balanciert die Klammern (kennt Strings, Kommentare, Regex-Literale); `evalFunction(src)` wertet via `new Function('return ('+src+');')()` OHNE jeden Scope aus. Folge: Die Funktion muss eine **top-level `function NAME(...)`-Deklaration** sein und darf **keine Globals** lesen (sonst `ReferenceError`). Konstanten/Tabellen entweder als Parameter übergeben oder mit `extractVarLiteral`/`evalInScope` in einen Scope injizieren.

**Bestehende extrahierte Funktionen (so schreiben):**

```javascript
// index.html:904 - rein, nur Parameter, liefert String-Entscheidung

}
// index.html:1343 - Einzeiler, keine Globals
function safePhoto(v){ return (typeof v==='string' && /^data:image\/(png|jpe?g|webp|gif);base64,[A-Za-z0-9+/=\s]+$/i.test(v)) ? v : ''; }
```

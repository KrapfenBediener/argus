## RPC-Verträge (verbindlich für die Client-Pläne 05/06)
Alle: `returns jsonb language plpgsql security definer set search_path to 'public'`, `grant execute … to anon`; Fehler als `{"error":"…"}` (nie Exception); Zeit = `(extract(epoch from clock_timestamp())*1000)::bigint`; Berechtigungsgrenze wie `argus_claim_device` (0022): `argus_is_master()` ODER `argus_praesidium_id()` = `ccps.praesidium_id`; Reihenfolge der Prüfungen: CCP existiert („CCP nicht gefunden") → Berechtigung („Keine Berechtigung") → Rest.
- `argus_device_heartbeat(p_ccp_id uuid, p_dev int, p_operator text, p_open_n int, p_ver text, p_rejoin boolean default false)` → offen: `{now, closed:false, left_at, lost_at}`; geschlossen: `{now, closed:true, closed_at, purge_after, photo_purge_after}` (keine Schreibwirkung); `p_dev` außerhalb `1..least(99, greatest(next_device,1))` → `{error:'Ungültige Gerätenummer', now}`. Upsert auf `(ccp_id, device_no)`: operator ≤ 40 Zeichen, open_n auf 0..9999 geklemmt, app_version ≤ 16, last_seen = now, first_seen nur beim Anlegen, `lost_at/lost_by := null` (Lebenszeichen schlägt Vermutung), `left_at/left_by := null` NUR bei `p_rejoin` (dann, falls vorher gesetzt, governance_log `geraet_wieder_beigetreten`).
- `argus_device_leave(p_ccp_id uuid, p_dev int, p_operator text, p_open_n int)` → `{ok:true, now, left_at}`; setzt left_at = now, left_by, open_n, last_seen; governance_log `geraet_verlassen` (detail `{dev, open_n}`); geschlossener CCP → `{closed:true, now}` ohne Schreibwirkung.
- `argus_device_mark(p_ccp_id uuid, p_dev int, p_lost boolean, p_by text)` → Zeile muss existieren (`{error:'Gerät unbekannt'}`); p_lost → lost_at = now, lost_by; sonst lost_at/lost_by = null; governance_log `geraet_abgemeldet` bzw. `geraet_abmeldung_aufgehoben` (detail `{dev, open_n}`); geschlossen → `{closed:true}`.
- `argus_log_herkunft(p_ccp_id uuid, p_dev int, p_weg text, p_ids text[], p_kuerzel text default '')` → p_weg ∈ {'direkt','nachgereicht'} (sonst `{error:'Ungültiger Weg'}`); CCP offen ODER innerhalb der 24-h-Nachfrist; ids auf 200 gekürzt, nur Muster `^[A-Za-z0-9_-]{1,40}$`; governance_log action `herkunft`, detail `{dev, fuer:p_dev, weg, ids, n}` → `{ok:true, n}`.
- `argus_late_push(p_ccp_id uuid, p_dev int, p_rows jsonb, p_kuerzel text default '')` → nur wenn `closed_at is not null` (offen → `{error:'CCP offen'}`), `now < closed_at + 86400000` (sonst `{error:'Nachfrist abgelaufen'}`), `purge_after is null or now < purge_after`, Gerät `p_dev` in `ccp_devices` eines CCP desselben Verbunds (`merge_group_id`) oder des CCP selbst (sonst `{error:'Gerät unbekannt'}`), `jsonb_typeof(p_rows)='array'`, ≤ 200 Elemente, `pg_column_size(p_rows) <= 10485760`. Je Element nur Whitelist-Spalten (id, ccp_id, num, ccp, cat, status, prio, ready, tq_start, tq_site, created, last_triage, updated, name, age, gender, allergies, pup_re, pup_li, vit, tx, inj, moi, injury, fr, notes, by, photo, fts, deleted_at, deleted_by, deleted_dev — NIE locked_*, conf); `ccp_id` muss zum Verbund gehören (sonst übersprungen); `photo := null`, wenn `photo_purge_after <= now`; Schreiben per `insert … on conflict (id) do update set <Whitelist> = excluded.<…>` (Merge-Trigger greift). governance_log `herkunft` detail `{dev, fuer:p_dev, weg:'nachfrist', ids, n}` → `{ok:n, skipped:m, now}`.
- `argus_server_time()` → `{now, v:26}`.

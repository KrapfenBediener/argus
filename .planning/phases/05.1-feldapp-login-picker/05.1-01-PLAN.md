## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Feld-App/Client → DB (RLS) | Untrusted JWT (anon role) löst patients/ccps-DML aus; Trigger laufen serverseitig |

| T-051-03 | Tampering | audit_log append-only umgehen | mitigate | Kein anon-INSERT/UPDATE/DELETE-Grant; RLS nur SELECT (argus_is_master); kein update/delete-Policy; Retention nur über kontrollierten Purge (0016) |

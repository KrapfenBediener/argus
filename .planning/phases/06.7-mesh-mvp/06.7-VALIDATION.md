## Sampling Rate

- **After every task commit:** `node --test tests/mesh.test.cjs && node scripts/check-syntax.mjs` (Plan 02 zusätzlich `sh native/scripts/mesh-check.sh`)
- **After every plan wave:** `npm run ci`
- **Before `/gsd-verify-work`:** `npm run ci` grün + `npm run check:rls` + Probe 0030 belegt + Zwei-iPhone-Checkliste (Plan 05) vollständig oder dokumentiert vertagt
- **Max feedback latency:** 10 s (Unit); 30 s (Swift-Typecheck)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Sitzungs-Guard mit Einzelwert hätte die Kaltstart-URL nach einem Warmstart-Reload erneut angewendet**
- **Found during:** Task 2 (Entwurf `consumeLaunchUrl`)
- **Issue:** Der Plan sah `sessionStorage.getItem('argus_launch_consumed')===url` vor (nur die letzte URL). Ablauf: Kaltstart per Link A (konsumiert A) → später Warmstart-Link B (konsumiert B, Reload) → `nativeStartup()` ruft `getLaunchUrl()`, das weiterhin A liefert → A ≠ B → A würde erneut in den Hash geschrieben und B überschrieben (bzw. ein verbrauchter Code erneut getauscht).
- **Fix:** Liste der konsumierten URLs (max. 20) statt Einzelwert; Test „Kaltstart-URL darf nach einem Warmstart-Reload nicht erneut greifen“.
- **Files modified:** index.html, tests/native.test.cjs
- **Verification:** `node --test tests/native.test.cjs` — Test `consumeLaunchUrl` grün (A → true, A → false, B → true, A → false)
- **Committed in:** d59dbd4

**2. [Rule 2 - Missing Critical] `launchHashFrom` reicht nur den validierten Wert weiter, nicht den rohen Fragment-Teil**
- **Found during:** Task 2 (Threat-Register T-06.6-10 „unbekannte Fragmente werden verworfen“)
- **Issue:** Der Plan-Text („liefert den Fragment-Teil der URL, wenn … etwas findet“) hätte z. B. `#code=ABCD-EFGH&evil=…` unverändert in `history.replaceState` geschrieben.
- **Fix:** Rückgabe `'#code='+extractInviteCode(frag)` bzw. `'#inv='+extractInviteToken(frag)`; Test mit Fremdinhalt im Fragment.
- **Files modified:** index.html, tests/native.test.cjs
- **Verification:** `launchHashFrom('argus://unlock#code=ABCD-EFGH&evil=<img onerror=1>')` → `'#code=ABCD-EFGH'`
- **Committed in:** d59dbd4

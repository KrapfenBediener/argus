## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node:test` (Node 22), zero-dependency; reine Funktionen aus `index.html` via `tests/_extract.cjs`; Datei-/Binär-/XML-Prüfungen für `native/` |
| **Config file** | none — `package.json` scripts `check:syntax`, `test`, `ci` (Root, unverändert); `native/package.json` Skripte `sync`, `version:set`, `version:bump`, `assets`, `swift:add`, `ios:sync`, `ios:open`, `ios:doctor` |
| **Quick run command** | `node --test tests/native.test.cjs` |
| **Full suite command** | `npm run ci` (= `check:syntax` + `node --test tests/*.test.cjs`, nimmt `native.test.cjs` automatisch mit) |
| **Estimated runtime** | ~5–12 s (Kopierskript läuft zweimal in Temp-Ordner) |

**Basislinie (2026-10-17):** `npm run ci` grün bei 0.34.5 (sw ccp-shell-v92). Kein Xcode auf dem Mac (nur CLT) → alle Gates sind reine Dateiprüfungen; `swiftc -frontend -parse` und `plutil -lint` laufen nur auf macOS (CI Ubuntu: `t.skip`).

## Sampling Rate

- **After every task commit:** `node --test tests/native.test.cjs` (+ `node scripts/check-syntax.mjs` und `node --test tests/consistency.test.cjs tests/security.test.cjs`, wenn `index.html` berührt wurde)
- **After every plan wave:** `npm run ci`
- **Before `/gsd-verify-work`:** `npm run ci` grün + Checkpoint A protokolliert (Simulator-Smoke-Test, Annahmen A1/A2/A7/A8) + Owner-Signale B/C (oder „C ausstehend“ dokumentiert)
- **Max feedback latency:** 12 seconds

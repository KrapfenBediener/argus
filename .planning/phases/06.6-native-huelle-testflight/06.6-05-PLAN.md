## Fakten für die Doku (RESEARCH §Frage 1/5/6, §Pitfalls, §Checkpoint-Liste)
- Xcode 26.x (App Store, kostenlos), macOS ≥ 15.6 (vorhanden 15.7); Plattenplatz: ≥ 40 GB frei empfohlen (Xcode + iOS-Simulator-Runtime; aktuell ~34 GB → vorher aufräumen, `df -h /`).
- Nach Installation: Xcode einmal öffnen (Lizenz akzeptieren, Komponenten installieren), Terminal: `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`, `xcodebuild -version`, `xcodebuild -runFirstLaunch`; iOS-Simulator-Runtime: Xcode → Settings → Components (oder `xcodebuild -downloadPlatform iOS`); Prüfung `xcrun simctl list runtimes`.
- Projekt: `cd native && npm ci` (falls `node_modules` fehlt), `npm run ios:sync`, `npm run version:set`, `npm run ios:doctor` (erst mit Xcode grün), `npm run ios:open` (öffnet `App.xcodeproj`, SPM-Paketauflösung läuft beim ersten Öffnen — Netz nötig; `File → Packages → Resolve Package Versions` bei Problemen).
- Vor Xcode ist die Warnung „Unable to find xcodebuild. Skipping xcodebuild clean step…“ bei `cap sync` normal.
- Pfad A: Zielgerät in der Toolbar (iPhone mit Dynamic Island wählen), Target `App` → Signing & Capabilities → Team „None“ genügt für den Simulator; ▶ Run (⌘R). Simulator hat keine Kamera; Standort: Features → Location → Custom Location; Netz: WLAN des Macs aus; Deep-Link nur per Terminal `xcrun simctl openurl booted "argus://unlock#code=XXXX-XXXX"`; Drehen ⌘← / ⌘→ (Portrait-Lock prüfen); Hintergrund: Device → Home (⇧⌘H), zurück über App-Switcher; Neustart: App im Simulator beenden (App-Switcher nach oben wischen) und neu öffnen.
- Pfad B: Xcode → Settings → Accounts → „+“ → Apple-ID; Target App → Signing & Capabilities → „Automatically manage signing“ → Team „<Name> (Personal Team)“; Bundle-ID bleibt `de.gaborszeman.argus` (bei Konflikt Suffix anhängen — dann `appId` in `native/capacitor.config.json` ebenfalls ändern und `npm run ios:sync`); iPhone per Kabel, „Diesem Computer vertrauen“, Entwicklermodus (Einstellungen → Datenschutz & Sicherheit → Entwicklermodus, Neustart); Gerät in Toolbar wählen → Run; am iPhone: Einstellungen → Allgemein → VPN & Geräteverwaltung → Entwickler-App vertrauen. Grenzen (freie Apple-ID): Signatur ~7 Tage (danach erneut aus Xcode starten), max. 3 solcher Apps je Gerät, kein TestFlight/App Store, keine Associated Domains.
- Pfad C: Apple Developer Program als Einzelperson (99 USD/Jahr, Apple-Account mit 2FA, Freigabe meist < 48 h); Xcode → Accounts → Team = das Programm-Team (nicht Personal); App Store Connect → Apps → „+“ → Neue App: Plattform iOS, Name „ARGUS“, Primärsprache Deutsch, Bundle-ID aus der Liste (erscheint nach dem ersten Signing mit dem Programm-Team bzw. über Certificates, Identifiers & Profiles → Identifiers), SKU frei (z. B. `ARGUS-IOS`); Zielgerät „Any iOS Device (arm64)“ → Product → Archive → Organizer → Distribute App → App Store Connect → Upload (automatische Signatur, Symbole hochladen); Verarbeitung 5–30 min (E-Mail); TestFlight-Tab → Build erscheint; Export-Compliance wird dank `ITSAppUsesNonExemptEncryption=false` nicht abgefragt; Interne Tests → Gruppe anlegen (z. B. „ARGUS Tester“) → Tester = App-Store-Connect-Nutzer (Benutzer und Zugriff → „+“, Rolle „Entwickler“ oder „Marketing“ reicht), ≤ 100; Tester installieren die TestFlight-App, nehmen die Einladung an; Builds laufen 90 Tage; externe Tester (≤ 10 000, Beta-App-Review des ersten Builds, öffentlicher Link) als Option; „Was testen“-Notizen je Build; Datenschutz-Angaben in App Store Connect (Vorlage aus dem lokalen Datenschutz-Dossier; **nicht** in diese Doku).
- Versionen: `APP_VERSION` ↔ `MARKETING_VERSION` (CFBundleShortVersionString), `native/version.json` ↔ `CURRENT_PROJECT_VERSION` (CFBundleVersion, muss je Upload steigen); `npm run version:set` nach jedem App-Release, `npm run version:bump` vor jedem Upload; `tests/native.test.cjs` erzwingt Gleichheit (D6.6-07).
- Troubleshooting: „Unable to find xcodebuild“ (vor Xcode normal; sonst `xcode-select -s`), Paketauflösung hängt (Netz; Reset Package Caches), „No profiles for …“ (Team wählen/Bundle-ID), „Untrusted Developer“ (Geräteverwaltung), Kamera-Absturz (Usage-Text fehlt → Info.plist), Install-Anleitung statt Code-Einlösung (Bridge nicht aktiv → `www` aktuell? `npm run ios:sync`), weißer Bildschirm (`public` leer → `npm run ios:sync`), Zugang nach Neuinstallation weg (gewollt: Keychain-Reste werden verworfen), Export-Teilen fehlt (Befund melden → Plan B `@capacitor/share`), Plattenplatz, „Build-Nummer bereits verwendet“ (version:bump), Simulator-Deep-Link nur per `simctl`.
- D-06: Leitungs-/Lage-Seiten nur als `docs/leitung-*.html` / `docs/lage-*.html` bezeichnen. Keine Team-ID, keine ASC-IDs, keine Codes.

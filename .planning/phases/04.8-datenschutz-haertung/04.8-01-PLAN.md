# Plan 04.8-01: T8 — Externe Laufzeit-Abhängigkeiten entfernen

**Phase:** 4.8 — Datenschutz-Härtung
**Wave:** 1 (unabhängig, parallel zu 04.8-02 möglich)

## Objective

Die App lädt zur Laufzeit nichts mehr von Drittanbieter-Domains (SPEC T8):
Supabase-JS wird als feste Version lokal eingebunden (statt cdn.jsdelivr.net),
die IBM-Plex-Schriften werden self-hosted (statt fonts.googleapis.com /
fonts.gstatic.com). Damit entfallen IP-Übermittlungen an Dritte bei jedem Start
und die Verfügbarkeits-Abhängigkeit im Einsatz. Offline-Verhalten bleibt
unverändert oder wird besser (alles im SW-Precache).

Output: `vendor/supabase.js`, `fonts/*.woff2`, angepasste `index.html`/`sw.js`,
aktualisierte `THIRD_PARTY_NOTICES.md`, Release-Bump.

## Context

- `index.html` Zeile 13–15: preconnect + Google-Fonts-Link + jsdelivr-Script (zu ersetzen)
- `sw.js` Zeile 12–16: `PRECACHE_URLS` enthält die Google-Fonts-CSS-URL; Zeile ~110–120: Sonderbehandlung für `fonts.googleapis.com`/`fonts.gstatic.com` im fetch-Handler
- `docs/fonts/` enthält bereits: ibm-plex-sans-400/500/600/700.woff2, ibm-plex-mono-600/700.woff2 (Mono 500 fehlt)
- Die App fordert aktuell per Google-Fonts-URL an: Sans 400;500;600 und Mono 500;600
- Kein node verfügbar: Downloads via `curl`, Skript-Hilfen via `python3`, JS-Syntax-Check via `osascript -l JavaScript`
